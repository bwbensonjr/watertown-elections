# Watertown Elections

Voter information and results for Watertown, MA municipal elections.

## Results website

Browse results for every election from 2017–2025, with drill-down from
citywide totals to precinct-by-precinct results and a map of the winning
candidate in each precinct:

**https://bwbensonjr.github.io/watertown-elections/**

The site is a zero-build static site in [`docs/`](docs/), served by GitHub
Pages. Its data (`docs/data/elections.json`) is generated by the R pipeline in
[`results/process-results.R`](results/process-results.R); the precinct map uses
the boundaries in [`docs/data/precincts.geojson`](docs/data/precincts.geojson).
